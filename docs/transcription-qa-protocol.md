# Transcription QA protocol

Formalization and transcription QA proceed in parallel but have different
authorities.

When Lean work suggests a German-source defect, record and send:

1. work, section/theorem, printed page, and controlled source line;
2. current German text and the proposed reading;
3. the mathematical reason the current reading fails or is suspicious;
4. primary-witness evidence, if available;
5. confidence and whether historical spelling or notation is involved.

The canon owner decides the German text. This repository may freeze a source
snapshot and annotate a discrepancy, but it must not silently patch the canon.
Likewise, a successful Lean proof certifies only the formal statement under its
explicit assumptions; it does not certify prose, pagination, layout, or the
completeness of a paper.
